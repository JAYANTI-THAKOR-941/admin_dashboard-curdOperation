# Product Management Dashboard

Express-style server-side product CRUD project with database configuration, product model, controller, routes and EJS views.

## Project structure

`config/db.js`, `models/Product.js`, `controllers/productController.js`, `routes/productRoutes.js`, `views/`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/admin_dashboard-curdOperation.git
cd admin_dashboard-curdOperation
```

Install dependencies in the root with `npm ci`. Configure the database connection, then inspect the package scripts or run `node index.js`.
